# Como Contribuir (Contributing)

Obrigado por considerar contribuir com o **Focus CLI**! Pessoas com TDAH, estudantes e trabalhadores focados agradecem a sua ajuda em evoluir essa ferramenta.

## Passos para contribuir

1. **Faça um Fork** do repositório público.
2. **Clone** o seu repositório localmente.
3. Configure a versão do Node.js recomendada (>= 18.x).
4. Crie uma **Branch** com sua nova funcionalidade ou correção de bug (`git checkout -b feature/MinhaNovaFeature`).
5. **Faça o Commit** de suas mudanças (`git commit -m 'Feat: Adicionando X'`).
6. Envie para o **Branch remoto** (`git push origin feature/MinhaNovaFeature`).
7. Simplesmente abra um **Pull Request**.

## Relatando Bugs
- Certifique-se de procurar por Issues parecidas [no repositório].
- Descreva detalhadamente o problema (inclua prints, sua versão de sistema operacional e de onde partiu).

## Diretrizes de Código
Este projeto usa JavaScript Vanilla sem dependências para se manter ultra-leve. Evite adicionar bibliotecas pesadas do NPM a menos que sejam essenciais e discutidas em um Issue primeiro.

Obrigado!
